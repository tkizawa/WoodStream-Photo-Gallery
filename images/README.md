# 写真フォルダの配置ガイド (Photo Organization Guide)

本ギャラリーは、この `images/` フォルダ内のフォルダ構造をそのまま **「アルバム名」** と **「撮影日（日付）」** として自動認識します。

---

## フォルダ構成ルール

以下のように配置してください：

```text
images/
  ├── [アルバム名]/
  │     └── [撮影日 (YYYY-MM-DD)]/
  │           ├── IMG_0001.JPG
  │           ├── IMG_0002.JPG
  │           └── ...
  │
  └── [別のアルバム名]/
        └── 2026-05-02/
              └── ...
```

### 具体例
```text
images/
  ├── 風景・ネイチャー/
  │     ├── 2026-04-10/
  │     │     ├── DSC_1001.JPG
  │     │     └── DSC_1002.JPG
  │     └── 2026-05-02/
  │           └── DSC_2001.JPG
  │
  └── 都市・スナップ/
        └── 2026-06-15/
              ├── IMG_5001.JPG
              └── IMG_5002.JPG
```

---

## ヒント・注意点
- **撮影日フォルダ名**: `2026-05-02` のような `YYYY-MM-DD` 形式が最も推奨されます（自動ソートや表示が綺麗になります）。
- **対応画像形式**: `.jpg`, `.jpeg`, `.png`, `.webp`
- **EXIF情報**: カメラから書き出された JPEG ファイルをそのまま配置すれば、撮影メタデータ（シャッタースピード、F値、ISO、カメラ・レンズ名など）が自動的に抽出・表示されます。
