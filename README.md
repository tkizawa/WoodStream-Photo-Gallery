# WoodStream Photo Gallery

写真を公開・閲覧するためのプロフェッショナルなWebギャラリーサイトです。  
500pxスタイルのタイルグリッドレイアウト、スムーズなフェードインアニメーション、そして写真のEXIF情報（カメラ、レンズ、撮影パラメータ一覧）を表示する詳細Lightboxビューを搭載しています。

---

## 主な機能・特徴

1. **フォルダ構造と完全連動**
   - `images/`（または `imeges/`）配下のサブフォルダを**アルバム**として自動認識します。
   - アルバム内の日付サブフォルダ（例: `2026-05-02`）を**撮影日グループ**として自動整理します。
2. **トップページ（アルバム一覧）**
   - アルバム一覧をカード形式で表示し、各アルバム内の最新写真をカバーサムネイルとして自動プレビュー。
   - アルバム内の撮影回数（フォルダ数）、写真総数をバッジ表示。
3. **アルバム詳細（撮影日一覧）**
   - アルバムをクリックすると、撮影日ごとのフォルダを代表写真のサムネイル付きで一覧表示。
4. **写真ギャラリー（500px風タイル表示）**
   - 撮影日フォルダを開くと写真を一覧表示。
   - 写真のアスペクト比（縦横比）を保ちつつ、行ごとに美しく整列する **500pxスタイルのタイルレイアウト（Justified Grid）**。
   - 写真のサムネイルは **順にジワッと浮かび上がるスタッガーアニメーション**（Staggered Fade-in）。
   - ホバー時にカメラ機種や撮影設定のクイックバッジがフェードイン。
5. **写真拡大モーダル（Lightbox & EXIFサイドパネル）**
   - 写真をクリックするとフルスクリーン拡大表示。
   - 右側に洗練された **撮影データ（EXIF）一覧サイドパネル** を表示：
     - 📷 **カメラ機種名**（例: `Canon EOS R8`）
     - 🔭 **レンズ名**（例: `RF100-400mm F5.6-8 IS USM`）
     - ⚙️ **撮影パラメータ（サツエオパラメータ）**
       - 焦点距離（35mm判換算含む）
       - 絞り値（F値: `f/8`, `f/9` 等）
       - シャッタースピード（`1/160s`, `1s` 等）
       - ISO感度（`ISO 100`, `ISO 10000` 等）
       - 露出補正（`0 EV`, `+0.7 EV` 等）
       - 露出プログラム（絞り優先、シャッター優先、マニュアル等）
       - 測光方式 / ホワイトバランス / フラッシュ状態
       - 画像解像度 & アスペクト比 / ファイルサイズ / 撮影日時
   - キーボード操作対応（`←` 前の写真 / `→` 次の写真 / `Esc` 閉じる / `F` 等倍ズーム切替）。
6. **パフォーマンス最適化**
   - 高解像度写真（10MB〜15MB）でも瞬時に表示できるよう、WebPサムネイルの自動オンデマンド生成・キャッシュを搭載。

## 起動方法

### ローカルサーバーでの実行（推奨）

```bash
# 依存関係のインストール（初回のみ）
npm install

# サーバー起動
npm start
```

ブラウザで `http://localhost:3000` を開きます。

### 静的サイトのビルド（GitHub Pages / 静的ホスティング用）

```bash
npm run build
```

`dist/` フォルダに静的HTML・CSS・JS・サムネイル・JSONデータが一式書き出されます。

---

## 写真の追加方法

`images/` フォルダ内に、以下のように配置するだけで自動的に反映されます：

```text
images/
  └── [アルバム名]/
        └── [撮影日 (YYYY-MM-DD)]/
              ├── IMG_0001.JPG
              └── IMG_0002.JPG
```
